# 个人Opencode插件集合

## 插件列表

| 插件名称       | 描述                                             |
| -------------- | ------------------------------------------------ |
| claude-mcp     | 让opencode能够读取claude格式的mcp插件            |
| skill-override | 在不修改skill源文件的情况下，修改skill的meta信息 |
| packyapi       | packyapi的provider插件                           |
