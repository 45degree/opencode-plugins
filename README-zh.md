# 个人Opencode插件集合

## 插件列表

| 插件名称                | 描述                                                                    |
| ----------------------- | ----------------------------------------------------------------------- |
| claude-mcp              | 让opencode能够读取claude格式的mcp插件                                   |
| skill-override          | 在不修改skill源文件的情况下，修改skill的meta信息                        |
| newapi-provider         | 在 OpenCode 中接入多个 New API 实例和 Provider 分组                    |
| system-prompt-templates | 系统提示词模板插件, 用于根据不同模型，不同provider,从模板动态生成提示词 |
